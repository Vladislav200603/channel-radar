# ADR-003: Gemini digest як некритичний адаптер

- Статус: прийнято
- Дата: 2026-09-16

## Контекст

AI-шар обов'язковий, але free quota, timeout або provider outage не повинні робити
дашборд недоступним. На момент реалізації моделі, згадані в умові, вже deprecated.

## Рішення

Використати актуальну stable `gemini-3.8-flash` через REST adapter. Генерація запускається
окремою дією, отримує не більше 40 публічних постів за сім днів і зберігає лише успішний
результат. Provider/model задаються environment. Помилки повертаються як domain result,
а не exception до web layer.

## Наслідки

- ingestion і звичайні сторінки не залежать від Gemini;
- попередній digest лишається доступним під час outage;
- prompt і response легко замінити іншим provider;
- Free Tier може використовувати публічний контент для покращення продуктів Google —
  це прийнятно лише тому, що в prompt немає приватних даних.
